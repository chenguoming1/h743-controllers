# V17 exclusions and replay limits

Twelve native/mechanical export paths are excluded, each with exact byte count and SHA256 in tests/checkpoint47/raw-evidence.json. Several point to identical content; hashes do not imply that payload bytes are bundled. Selected authoritative construction/reference reports are compressed and deduplicated, while routed boards and all paired project inputs recover exactly via sessions/recovery-v17. No new large search diagnostic dumps, native exports, binary runtimes, JVM/FEM payloads, caches, Git state or isolated flash/ADC/PORT_C candidate trees are included.

Original native full-width/annular geometry, actual pad-cut graphs, native DRC/ERC gates, exporter/probe tests, refill and power/VCAP solves are not rerun. The original pure parser-based owner integration checks and the support adapter are the only owner routines reexecuted. The checker uses exact parser definitions from the original helper without importing its unrelated pcbnew command-line program. The payload supplies portable native construction inputs, but not native runtime binaries or all inputs for complete historical validation replay.

Restore or regenerate omitted reports with the exact paired boards and pinned KiCad10.0.6/exporter behavior, then verify exact hashes before native replay. The packet does not guarantee regenerated native bytes across different builds. Existing V16 omissions/limitations remain documented in docs/historical-v16 and its inherited evidence. Current power/VCAP, I2C electrical, fabrication and flight qualification remain unestablished.
