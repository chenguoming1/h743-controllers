===============================
IBIS files for STM32F7 devices:
===============================

The package contains :


   + IBIS Files for STM32F745_746_756 devices on different packages :

	  o LQFP208
	  o LQFP176
	  o LQFP144
	  o LQFP100
	  o TFBGA216
	  o UFBGA176
	  o WLCSP143

   + IBIS Files for STM32F765_767_777 devices on different packages :

	  o LQFP208
	  o LQFP176
	  o LQFP144
	  o LQFP100
	  o TFBGA216
	  o UFBGA176

   + IBIS Files for STM32F768A_778A_769_779 devices on different packages :

	  o LQFP208
	  o LQFP176
	  o TFBGA216
	  o WLCSP180

   + IBIS Files for STM32F7x2 devices on different packages :

	  o LQFP176
	  o LQFP144
	  o LQFP100
	  o LQFP64
	  o UFBGA176

   + IBIS Files for STM32F7x3 devices on different packages :

	  o LQFP176
	  o LQFP144
	  o UFBGA176
	  o UFBGA144
	  o WLCSP100
