# Firmware compatibility reference

`RDMS-NEXUS_F7.config` is an unchanged compatibility reference from the Rotorflight target repository, pinned to commit `1d9cb4dc6f85c7895c2b089f4b8aa776ca3d3bd3`, blob `ca042b1f51a341a46980cb9aba78420beab48be7`:

https://github.com/rotorflight/rotorflight-targets/blob/1d9cb4dc6f85c7895c2b089f4b8aa776ca3d3bd3/configs/RDMS-NEXUS_F7.config

The configuration remains attributed to its upstream authors. The pinned repository root has no LICENSE file; this project does not assign its own license to that copied reference. No firmware binary is supplied. Obtain firmware through the official Rotorflight distribution and review its license and release instructions. The hardware design and RadioMaster branding are not copied from this configuration.

A matching resource map is not proof of hardware operation. Confirm the loaded target, sensor axes, receiver/output behavior, ADC readings, USB power sequencing and failsafes on a current-limited first article with motors disconnected before any flight evaluation.
